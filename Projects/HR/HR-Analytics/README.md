# HR Analytics Dashboard

## 📌 Overview
This project analyzes HR data to provide insights into employee attrition, workforce demographics, job satisfaction, and departmental performance.  
The dashboard highlights key HR metrics to support workforce planning and employee retention strategies.

## 🎯 Objectives
- Analyze employee attrition across departments  
- Monitor active employees and workforce demographics  
- Identify trends in employee satisfaction and performance  
- Compare income distribution by job role  
- Support HR decision-making with data-driven insights  

## 📂 Dataset
- **Source:** HR Analytics dataset  
- **Rows:** 1,470 employee records  
- **Columns:** HR-related fields including age, department, education, job role, income, and attrition status  
- **Scope:** Employee workforce analysis  

## 📊 Key Metrics
- **Total Employees:** 1.47K  
- **Active Employees:** 1.233K  
- **Attrition Count:** 237  
- **Attrition Rate:** 16.12%  
- **Average Employee Age:** 37
